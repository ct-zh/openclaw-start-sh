# Prompt 模板库

使用时先根据下表选择文件，再按需读取对应模板；仅复制模板文件中的代码块内容提交给模型。

| 文件 | 模板 | 一句话用途 | 何时使用 |
| --- | --- | --- | --- |
| `question-clarification.md` | 苏格拉底式提问 | 通过有限追问澄清真正问题。 | 困惑、需求或问题表述模糊时。 |
| `learning.md` | 双层解释法 | 以小白版和专业版理解陌生概念。 | 学习术语、机制或技术概念时。 |
| `learning.md` | 反向拆解 | 拆解优秀案例并提炼可迁移规律。 | 想研究产品、页面、方案或流程时。 |
| `research.md` | 横纵分析法 | 从历史演化和横向比较研究对象。 | 需要系统研究公司、技术、行业或事件时。 |
| `research.md` | 事实核查 | 验证事实、推理链和结论边界。 | 判断观点、数据或方案是否可信时。 |
| `problem-solving.md` | 专家会诊 | 用互补视角对问题提出并互相质疑。 | 复杂问题涉及多个专业领域时。 |
| `problem-solving.md` | 第一性原理 | 从基本事实、目标和约束重新推导路径。 | 现有方案陷入补丁或路径依赖时。 |
| `problem-solving.md` | 跨领域借解 | 从其他领域寻找可迁移的解决机制。 | 行业内常规方案都无效或受限时。 |
| `decision-making.md` | 双向钢人论证 | 为两个方向构建最强论证后再决策。 | 两个方案均有道理、难以取舍时。 |
| `decision-making.md` | 最小实验 | 设计低成本、可逆的验证实验。 | 关键不确定性可通过现实反馈验证时。 |
| `self-reflection.md` | 挖掘隐藏天赋 | 通过多轮追问整理个人底层优势。 | 希望复盘能力、能量模式与职业倾向时。 |
| `self-reflection.md` | 人生设计术 | 用原型与多个路径规划未来方向。 | 希望梳理人生方向或职业选择时。 |

> 自我探索模板仅供反思和规划，不替代心理健康、医疗、法律或职业资格建议。
